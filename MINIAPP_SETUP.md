# EasyTrip Mini App — Passport prototype v1

Добавлено: нижняя навигация (Главная/Паспорт/Поездки/Избранное/Профиль), экран паспорта со вкладками штампы/страны/карта, XP/уровни, демо-штампы, задания недели, Club статус. Добавление посещённой страны и получение штампа работают в демо. Состояние сохраняется локально в браузере через localStorage.

**Важно:** это фронтенд-прототип с демо-данными. Данные пока не синхронизируются с Telegram аккаунтом/сервером. Следующий этап — backend + БД, серверная проверка Telegram initData и синхронизация профиля. Подтверждение партнёрских покупок и реальные привилегии Club пока не подключены.

Разместить папку `miniapp` на HTTPS и задать `MINI_APP_URL`.


## Подключение к Telegram-боту (добавлено)

1. Разместите содержимое папки `miniapp` на HTTPS-хостинге (например, GitHub Pages).
2. В файл `.env` рядом с `bot.py` добавьте строку:
   `MINI_APP_URL=https://ваш-домен/`
3. Перезапустите бота.
4. В Telegram отправьте команду `/app` — бот покажет кнопку открытия Mini App.

Команда `/app` не вмешивается в существующий сценарий подбора путешествия. Если URL не задан, бот объяснит, что Mini App ещё не подключён.
